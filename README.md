### Emmet Noman

Computer science graduate (University of Lincoln, 2026). I build systems software: Windows tools, networking and real-time media, mostly in Rust, TypeScript and Python.

Selected projects. Most of the code is private and available on request.

- **zerodisk**: a Rust disk analyzer for Windows that reads the NTFS master file table directly. It scans a 1.8 TB drive in 7.7 s and has 156 tests.
- **zeronetwork**: a per-process network monitor for Windows, built on kernel ETW events. 53 tests.
- **star**: WebRTC voice and video calling on the web, Windows and Android.
- **Kernel**: a community-management platform for Discord servers, now in a staging pilot.
- **one-armed-cake**: a Raspberry Pi router with CAKE traffic shaping. On a slow DSL line under load, median latency fell from 165 ms to 18 ms.
- **My own Linux server**, which runs these projects, plus a private network via Tailscale (self-hosted Headscale).

I design, test and verify; much of the implementation is AI-assisted.
